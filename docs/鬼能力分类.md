# 本体厉鬼能力分类

> 扫描对象：`smfs2/mr`（比 1.5.0 新，个别判定可能有差异）。
> 目的：给「交错借规律」挑出真正能生效的类型。

## 一个前提：所有攻击都要求鬼域开启

`GhostEntity.tick` 里那一段的门是：

```java
if (!isSuppressed() && !isDeadlocked() && ghostDomainEnabled && hasGhostDomain) {
    // 才进入"遍历域内玩家 → 问 shouldAttackPlayer"
}
```

所以**不存在"不用鬼域也能主动袭击"的鬼**。所谓"用不用鬼域"的差别只在判定内部：
有没有额外检查"玩家是否在域内"。

## 真正决定"能不能借"的轴

影子实例是新建的，**玩家侧属性读得到，鬼自身的记忆读不到**。

| 判定依赖 | 影子能复现吗 | 交错效果 |
|---|---|---|
| 玩家状态（潜行/进食/在水里/低光） | ✅ 能 | 生效 |
| 双方距离 | ✅ 能 | 生效 |
| 世界方块（农田/门/掉落物） | ✅ 能 | 生效 |
| **鬼自身实例记忆**（新建的 map、阶段计时） | ❌ 空 map / 初始值 | **白借** |
| **鬼自身的静态记忆** | ✅ 共享 | 生效 |

这条比"有没有鬼域"重要得多：几乎所有白借都出在"判定读鬼自己的 map"。

## 分类总表（43 只）

### A. 纯距离 / 朝向（最纯粹，借来必生效）

| 鬼 | 判定 |
|---|---|
| 坟土鬼 `grave_earth_ghost` | 20 格内 |
| 新开鬼 `xinkai_ghost` | 半径内 |
| 鬼影头 `ghost_shadow_head` | 域半径常量内 |
| 鬼烟 `ghost_smoke` | ⚠ 恒 false（不主动杀） |
| 巨人鬼影 `giant_shadow_ghost` | 背对 + 距离 |
| 抬头鬼 `taitou_ghost` | 玩家抬头（pitch < -30）+ 32 格 |
| 埋头鬼 `ditou_ghost` | 玩家低头（pitch > 30）+ 距离 |
| 踩人鬼 `step_ghost` | 玩家比鬼低 1 格 + 28 格 |
| 遗忘鬼 `lost_ghost` | 只查保护（红烛/金棺/金块/免疫）—— 几乎无条件 |

### B. 玩家状态（借来生效，因为状态在玩家身上）

| 鬼 | 判定 |
|---|---|
| 衣服鬼 `clothes_ghost` | 距离 + 玩家没穿护甲 |
| 矿鬼 `mineral_ghost` | 距离 + 背包里有矿 |
| 疫鬼 `plague_ghost` | 距离 + 玩家患病 |
| 潜行鬼 `sneak_ghost` | 距离 + 玩家潜行 |
| 傀儡鬼 `puppet_ghost` | 距离 + 玩家静止 |
| 影子鬼 `shadow_ghost` | 距离 + 玩家处于低光 |
| 水鬼 `water_ghost` | 30 格 + 玩家在水里 |
| 庄稼鬼 `crop_ghost` | 24 格 + 踩在农田上 + 没穿金靴 |
| 食物鬼 `food_ghost` | 玩家正在吃东西 |
| 烧伤鬼 `burn_ghost` | 30 格 + 玩家在燃烧 |

### C. 玩家行为（借来生效）

| 鬼 | 判定 |
|---|---|
| 方块鬼 `block_ghost` | 玩家正在与方块交互 |
| 箱子鬼 `box_ghost` | 距离 + 正在开箱子（**静态 map**，影子共享） |
| 门鬼 `door_ghost` | 距离 + 正在开门 |
| 垃圾鬼 `trash_ghost` | 20 格 + 附近 6 格有掉落物 |
| 商人鬼 `ghost_merchant` | 32 格 + 玩家没带鬼钱 |
| 村民鬼 `villager_ghost` | 玩家攻击过村民（**静态**记忆，影子共享） |

### D. 视线（借来生效，但依赖站位）

| 鬼 | 判定 |
|---|---|
| 死亡视线 `death_sight_ghost` | 20 格 + 视角点积 ≥ 0.5 + raycast 无遮挡 |

### E. 依赖鬼自身记忆 → **借来必白借**

| 鬼 | 为什么 |
|---|---|
| 雾鬼 `fog_ghost` | 读 `playerMoveStartTicks`（**实例** map），影子是空 map，永远算不出"移动了多久" |
| 静悄悄 `silent_ghost` | 同上，实例 map + `lastAttackTime` |
| 跳跃鬼 `jump_ghost` | 读 `justJumped` / `jumpCooldown`，影子从未跳过 |
| 警官 `ghost_officer` | 要求玩家在域内 + 按"域内其他鬼的数量"算配额，影子不在任何域里 |

### F. 不主动杀人（无覆写或恒 false）—— 借来毫无意义

`crying` `ganshi_bride` `gong` `qiaomen` `suona` `ghost_smoke`（恒 false）
`ghost_child` `ghost_dream` `ghost_pressure` `ghost_wind` `giant_male_corpse`
`goods_seller` `luo_qian` `untouchable`（无覆写）

这些鬼的杀伤靠别的路径（靠近掉血、域内压制、仪式流程），`shouldAttackPlayer` 根本不用。

## 对交错池的结论

当前池子是 43 只全收。按上面分类：

- **能生效**：A + B + C + D = 约 27 只
- **白借**：E 的 4 只
- **无意义**：F 的 14 只（抽中它们等于少一条交错）

也就是**随机抽 3 条，平均有 1.2 条是废的**。这解释了实测里"三条全 0 命中"。

改进方向（按性价比）：

1. **池子里排除 F（14 只）**：零风险，立刻把废条率从 ~42% 降到 ~13%
2. **排除 E（4 只）**：需要按类名/路径维护一份小名单，成本略高
3. 更彻底：给每个类型标一个"可借等级"（数据包配置），但那是给外人用的，你自己维护时没必要

## 一个反直觉的发现

「静悄悄」和「雾鬼」看起来很适合作交错素材（"站着不动就被杀"很有记忆点），
但实际上**它们是最典型的白借**：判定全部建立在鬼自己记的"你什么时候开始动的"上面，
换个实例就全丢了。

这也是判断任何"别人的规律"能不能借的通用法则：
**看它判的是"你做了什么"，还是"我记得你做了什么"。**
