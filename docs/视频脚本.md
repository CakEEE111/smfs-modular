# 视频脚本：融合附属介绍

> 目标时长 4 分钟。结构是「钩子 → 一个核心演示 → 三个延伸 → 代价 → 收尾」。
> 每段都标了**该拍什么画面**，录制时按顺序走一遍即可。

---

## 标题候选

1. 把鬼打进木剑里 —— 神秘复苏「万物融合」附属
2. 任何物品都能变成灵异武器？这个附属做到了
3. 神秘复苏附属：一只鬼，五种用法

**一句话定位（口播第一句）**

> 「这个附属只做一件事：让**任何**物品都能融合厉鬼。」

---

## 分镜表

### 00:00 — 00:15 ｜钩子

**画面**：手持一把普通木剑，对着一只鬼挥两下（毫无反应，甚至被打）。
**口播**

> 「木剑打鬼，一点用没有。
> 现在我把这只鬼融进去——」
（切到融合界面，合入完成，词条出现）
> 「……还是这把木剑，但它现在能伤到鬼了。」

### 00:15 — 00:40 ｜是什么

**画面**：物品栏切到几件不同的东西（木剑、钻石剑、锄头），每件都带词条。
**口播**

> 「这是《神秘复苏》的一个附属，需要先装本体。
> 它不新增武器，也不新增防具——它让**你手上的东西**变成灵异物品。
> 剑、镐、锄头、甚至一根木棍，都能融。」

### 00:40 — 01:40 ｜核心：融合怎么玩

**画面**（按顺序，一镜到底最好）：

1. 打开灵异主界面 → 右侧「装置」按钮 → 两槽界面
2. 左槽放物品，右槽放鬼
3. 界面显示「压制值 / 需求值」
4. 点合入 → 成功提示 → 物品词条变化

**口播**

> 「入口在本体的灵异主界面里，右边多了一个『装置』按钮。
> 左边放要改的物品，右边放要融的鬼。
>
> 界面会算两个数：你的**压制值**，和这次融合的**需求值**。
> 压制够，直接成；压制不够，它会让你**赌一把**——赢了规律照样进去，输了挨反噬。
>
> 融进去之后，物品上会多出词条：它绑了哪只鬼、基础灵异伤害多少、继承倍率多少。」

**要点提醒（画面下方可打字幕）**

- 同一件物品可以叠多只鬼，但每多一只，成本按 75% 复利上涨
- 融进去的鬼会被消耗

### 01:40 — 02:20 ｜延伸一：技能

**画面**：手持融合物品 → 按 X → 面板列出技能 → 点一个 → 释放特效。

**口播**

> 「融进去的鬼，它的技能你能直接用。
> 按 X 打开面板，**手上拿的是哪件，就只看哪件的技能**。
>
> 而且不限本体那几十只鬼——任何附属的鬼，只要它的技能走本体的技能通道，
> 这里都会自动收录，不用写适配。」

**画面补充**：切到面板里一个来自别的附属的技能，点一下放出来。

### 02:20 — 02:50 ｜延伸二：被动也生效

**画面**：背包里放着融合物品（不手持），触发某个被动（例如免疫/感知）。
**口播**

> 「很多人会问：那被动呢？
>
> 本体判断『你有没有驾驭这只鬼』有两个入口，我们都接上了。
> 所以**只要物品在背包里**，鬼的被动就会生效——不需要拿在手上，也不需要塞进鬼槽。」

### 02:50 — 03:20 ｜延伸三：灵异伤害

**画面**：拿融合物品打鬼，鬼的灵异强度明显下降；再打普通怪，只有原版伤害。
**口播**

> 「重点来了：融合物品的伤害是**两份**。
> 一份是原版伤害，一份是**灵异伤害**——后者才打得动鬼。
>
> 每只融进去的鬼，会贡献它最大灵异的 10%，再加玩家自己灵异伤害的 50%。
> 融三只鬼，基础灵异伤害就是七八百，比本体最强的灵异武器还高一截。」

### 03:20 — 03:50 ｜延伸四：鬼也会变强

**画面**：一只鬼在玩家「按理不该死」的位置把玩家杀了；切命令 `/ghostmodules check`。

**口播**

> 「但它不是单向的。
>
> 新世界生成的鬼，会按难度**借用别人的杀人规律**——普通 3 条，困难 4 条。
> 也就是说同一只鬼，可能既按自己的规矩杀你，也按水鬼、按抬头鬼的规矩杀你。
>
> 想知道它借了谁，站它旁边敲 `/ghostmodules check`，会列出来。」

### 03:50 — 04:10 ｜代价

**画面**：融合失败 → 屏幕抖动 / 提示「灵异反噬」→ 面板灵异强度下降。
**口播**

> 「最后说代价。压制不够硬融，输了要付三样东西：
> 灵异强度、血量、还有鬼槽的复苏度。
>
> 而且融进去的鬼会**消耗**——所以这不是免费加强，是拿鬼换武器。」

### 04:10 — 04:30 ｜收尾

**画面**：一排融合好的物品摆在展示框里，镜头拉远。
**口播**

> 「总结一下：它不新增内容，它让**已有的东西**产生新的组合。
> 需要本体，Fabric 1.20.1。
> 链接在简介，玩得开心。」

## 录制前准备清单

| 项 | 说明 |
|---|---|
| 存档 | 创造模式 + 一个平坦场地 + 几只不同种的鬼（`/summon`） |
| 物品 | 木剑、钻石剑、锄头各一把（展示「万物可融」） |
| 鬼 | 至少准备 3 只：一只能融成功、一只压制不足用来演示赌、一只来自其他附属（演示技能自动收录） |
| 命令 | `/ghostmodules check`、`/ghostmodules list` 提前复制到聊天栏 |
| 镜头 | 融合界面那段一定要**一镜到底**，剪辑会破坏「原来这么简单」的观感 |
| 字幕 | 把「压制值 / 需求值 / 灵异伤害 / 反噬」四个词做成常驻角标，观众才跟得上 |

---

## 三个容易讲错的地方（口播注意）

1. **别说「融合后物品变强了」** —— 准确说是「多了一份灵异伤害」，原版伤害没变
2. **别说「所有鬼的规律都能借」** —— 交错只对新生成的鬼生效，且部分规律借来是无效的（依赖鬼自身状态的那些）
3. **别说「不需要本体」** —— 这是附属，本体是硬依赖
